# images フォルダ

タイルに表示するポケモンの画像を、ここに **PNG** で置いてください。
ファイル名は下の表のとおりです（すべて小文字・半角）。

- 推奨サイズ：**96×96px** の正方形、背景透過
- 置いていないポケモンは自動的に文字だけの表示になります（エラーにはなりません）
- 画像はページの表示速度に直結します。1枚 20KB 以下を目安に圧縮してください

## 画像の権利について

ポケモンの公式イラスト・ゲーム画面のスクリーンショットは株式会社ポケモンなどが権利を持っています。
公開サイトに載せる場合は、必ず自分で確認してから使ってください。

- 公式素材の無断転載や、他の攻略サイトからの画像の持ち出しは避けてください
- 株式会社ポケモンが公開している二次創作・ファンサイトに関するガイドラインを確認するのが確実です
- 自分で描いたイラストや、シルエットだけのアイコンに差し替えるのが一番安全です
