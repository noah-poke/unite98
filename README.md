# ユナイト98

ポケモンユナイトの使用可能ポケモンを、何も見ずに何体打ち込めるか挑戦するタイピングゲームです。
サーバー側の処理は不要で、静的ファイルを置くだけで動きます。

```
index.html
assets/style.css
assets/app.js
assets/roster.js   ← ポケモン一覧。更新するのはここだけ
images/            ← ポケモンの画像を入れる（README.md にファイル名一覧あり）
```

---

## 1. 公開のしかた

フォルダごとアップロードするだけです。おすすめは無料で使えて HTTPS が自動で付くところ。

- **GitHub Pages** … リポジトリに置いて Settings → Pages を有効化
- **Cloudflare Pages / Netlify** … フォルダをドラッグ&ドロップ

ローカルで動作確認するときは、ファイルを直接ダブルクリックするより簡易サーバーを立てたほうが確実です。

```bash
cd unite-quiz
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 2. セキュリティまわり

このサイトはユーザーのデータを何も受け取らず、外部にも一切送信しません。そのうえで次の対策を入れてあります。

**すでに入っているもの**

| 対策 | 内容 |
|---|---|
| CSP | `index.html` の meta タグで、自分のサイト内のファイル以外の読み込みを全部ブロック |
| 外部依存ゼロ | CDN・Webフォント・解析タグを一切使っていないので、外部サイトに閲覧者の情報が渡りません |
| XSS対策 | 入力文字を画面に出すとき `innerHTML` を使わず `textContent` のみを使用 |
| 保存データ | 自己ベストは閲覧者のブラウザ内（localStorage）だけ。サーバーには何も残りません |
| フォーム送信なし | `form-action 'none'` で、万一の外部送信を禁止 |

**サーバー側で追加してほしい設定**

meta タグでは指定できないものがあります。GitHub Pages では設定できませんが、Cloudflare Pages や Netlify なら `_headers` ファイルを置くだけです。

```
/*
  Strict-Transport-Security: max-age=31536000
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Content-Security-Policy: frame-ancestors 'none'
  Permissions-Policy: geolocation=(), camera=(), microphone=()
```

`frame-ancestors 'none'` は、他人のサイトにこのページを埋め込まれる（クリックジャッキング）のを防ぐものです。

**知っておいてほしいこと**

- 正解データは `roster.js` に入っているので、開発者ツールを開けば答えは見えます。静的サイトである以上これは避けられません。カンニング防止が必要なら、サーバー側で答え合わせする作りに変える必要があります。
- アクセス解析を入れたくなったら、CSP の `default-src 'none'` に引っかかります。解析タグのドメインを `script-src` と `connect-src` に追加してください。ただし外部に閲覧者の情報が渡るので、プライバシーポリシーの掲載も併せて検討を。

## 3. ポケモンを追加・修正する

`assets/roster.js` を開いて、該当する型の `list` に1行足すだけです。

```js
{ n:'ストリンダー', id:'toxtricity' },
```

- `n` … 画面に出る名前。判定にも使われます
- `id` … `images/` に置く画像のファイル名（拡張子なし）

ひらがな入力・記号・長音の違いは自動で吸収されます。それ以外の呼び方でも正解にしたいときは、同じファイルの `ALIAS` に足してください。

```js
'ストリンダー': ['ハイなすがた', 'ローなすがた'],
```

**現在のロスター（2026年8月時点・全98体）**

| 型 | 体数 |
|---|---|
| アタック型 | 27 |
| バランス型 | 35 |
| ディフェンス型 | 13 |
| スピード型 | 11 |
| サポート型 | 12 |

メガリザードンX / メガリザードンY / メガギャラドス / メガルカリオ は、元のポケモンとは別の1体として数えています。

## 4. 画像を入れる

`images/README.md` に98体分のファイル名の一覧があります。置いていないポケモンは文字だけで表示されるので、少しずつ足していけます。
公式画像の扱いについても同じファイルに書いてあるので、公開前に目を通してください。

## 5. 公開するときの表示まわり

`index.html` の OGP タグ（`og:url` と `og:image`）と `assets/app.js` の `SITE_URL` は、公開URL（`https://noah-poke.github.io/unite98/`）に設定済みです。URLを変更する場合はこの2箇所を書き換えてください。

フッターに「個人のファンサイトであること」「公式とは無関係であること」を明記してあります。公開前に消さないでください。
